# VibeHoster Publish

Скил для Codex и Claude Code: агент проверяет готовый сайт, помогает подготовить статическую сборку и публикует её через MCP VibeHoster.

> **Статус: локальный прототип.** Сейчас MCP VibeHoster доступен только на `http://localhost:18404/mcp` и должен быть отдельно запущен на вашем компьютере. Установка скила сама по себе не создаёт работающий хостинг. Публичный MCP для пользователей ещё не запущен.

## Установка через агента

Отправьте Codex или Claude Code ссылку вместе с просьбой:

> Установи скил VibeHoster Publish из https://github.com/VibeHoster/vibehoster-skill и помоги подключить его к моему MCP VibeHoster.

Скил находится в [`skills/vibehoster-publish`](skills/vibehoster-publish). После установки может понадобиться перезапустить агент, чтобы он обнаружил новый скил. Подключение MCP и вход в VibeHoster выполняются отдельно.

## Инструкция для агента по установке

1. Определите, работает ли пользователь в Codex или Claude Code. Установите каталог `skills/vibehoster-publish` целиком вместе с `scripts/`, не заменяя существующий одноимённый скил без согласования. В Codex можно использовать доступный установщик скилов с репозиторием `VibeHoster/vibehoster-skill` и путём `skills/vibehoster-publish`. В Claude Code пользовательский каталог скилов — `~/.claude/skills/vibehoster-publish`.
2. Проверьте, подключён ли MCP VibeHoster. Локальный сервер `http://localhost:18404/mcp` используйте только когда пользователь действительно запустил VibeHoster на своём компьютере. Если сервер не настроен, объясните это; не придумывайте публичный адрес и не просите пароль или токен в чате.
3. Для локального сервера команды подключения: `codex mcp add vibehoster --url http://localhost:18404/mcp` или `claude mcp add --transport http --scope user vibehoster http://localhost:18404/mcp`. При необходимости запустите `codex mcp login vibehoster` или `claude mcp login vibehoster`. Вход и подтверждение доступа пользователь проходит на странице VibeHoster.
4. После установки предложите пользователю открыть папку проекта и написать: «Используй vibehoster-publish и опубликуй этот проект». Не публикуйте файлы без такого запроса.

## Что умеет

- Проверять, подходит ли проект для статического хостинга, и объяснять ограничения серверной части и внешних сервисов.
- Упаковывать готовую сборку с `index.html`, HTML, CSS, JavaScript, JSON, изображениями и шрифтами в пределах поддерживаемых форматов.
- Передавать архив через одноразовое разрешение MCP без помещения содержимого архива в контекст модели.
- Возвращать адрес опубликованного сайта и результаты доступных проверок.

Готовая сборка может содержать приватные сведения или ключи: перед публикацией агент проверяет состав и сообщает об обнаруженных проблемах. Успешное открытие главной страницы не подтверждает работу форм и внешних API. Проекты с серверным кодом или внутренней базой могут потребовать отдельной адаптации.

## Состав

```text
skills/vibehoster-publish/
├── SKILL.md
└── scripts/
    ├── package_static.py
    └── upload_static.py
```

Скриптам нужен Python 3.9 или новее. Текущая реализация тестировалась локально на macOS и Linux; скрипт загрузки намеренно принимает только локальный адрес MCP. Для работы с будущим публичным MCP потребуется обновлённая версия интеграции.
